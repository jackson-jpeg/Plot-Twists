## Layer 3 screening over everything above

Run with the production matcher (`contentScreen.service`), not a copy of it.

**Zero hits.** Nothing in the 40 hands, the prompts, or all 509 catalog entries
matches a protected term or a real person.

**Read that as narrowly as it is meant, because this morning it was a false green.** The
screen is a fixed denylist. It finds terms somebody already thought to add — and it does not
read source files, so it returned this same clean sweep while the ensemble prompt said
*Structure it like "The Office" or "Community."* and the user prompt said *"Yoda talks like
Yoda"*. Both were shipping to the model on every round. Both are fixed, and a build-time
gate that reads the files as text now covers five of them.

What a clean sweep means: no *named* entity survived. It does not mean nothing is
recognisable, and it never will.

## Deliberate public domain — a judgement call to confirm or overrule

You said genre and public domain are allowed and under-used. They are now used, and only in
SETTINGS, never in the trait deck. The reason is that your two rules pull against each other:
