## Layer 3 screening over everything above

Run with the production matcher (`contentScreen.service`), not a copy of it.

**Zero hits.** Nothing in the 40 hands, the prompts, or all 509 catalog entries
matches a protected term or a real person.

**Read that as narrowly as it is meant, because this morning it was a false green.** The
screen is a fixed denylist. It finds terms somebody already thought to add — and it does not
read source files, so it returned this same clean sweep while the ensemble prompt said
*Structure it like "The Office" or "Community."* and the user prompt said *"Yoda talks like
Yoda"*. Both were shipping to the model on every round. Both are fixed, and a build-time
gate that reads the files as text now covers five of them.

What a clean sweep means: no *named* entity survived. It does not mean nothing is
recognisable, and it never will.

## Real scripts — ENSEMBLE, live API

Generated by `scripts/real-generation.ts` against the real API, through the production
`generateScript` path — same prompts, same model, same parsing as a live round.

**Cast size: 8 traits.**

**One thing to notice before you read them, and it replaces what this section used to say.**
The earlier version of this packet admired the fact that nobody told the model to name the
characters and it invented names anyway — Marcus, Denise, Paulo — calling that "the grammar
doing what it was supposed to do". It was not. A player's identity in this product is the
verbatim text of their trait card, and `MobileTeleprompter` decides whose phone says YOUR
TURN by comparing that string to `line.speaker` with `===`. Invented names meant that
comparison was false for every line of every script ever generated: **zero of eight traits
matched in any of the three previous scripts.** Every part belonged to nobody, and no player
has ever been told a line was theirs.

The prompt now hands the model the cast list and demands those exact strings back, and the
server snaps near-misses and logs anything it cannot bind. That is why the speaker labels
below are sentences rather than names. It reads oddly on the page and correctly in the room:
the label above a line is the card in somebody's hand.
